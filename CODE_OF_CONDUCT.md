# Code of conduct

This repository follows the [Civil Service Code](https://www.gov.uk/government/publications/civil-service-code/the-civil-service-code) values of integrity, honesty, objectivity and impartiality, and the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be kind and specific. Criticise work, not people. Don't share personal data, or anything from private channels, in issues or pull requests.

Report a problem with someone's conduct by raising an issue marked "conduct", or privately through the repository's security policy if it isn't safe to do so in the open.
