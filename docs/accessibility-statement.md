# Accessibility statement

Generated from `build/inv/docs71.py`, the same source as the page's statement (About, Accessibility).

This statement covers the GitHub Repos Asset Catalogue: the open edition published on GitHub Pages, and the government edition built from the same code. It aims to meet WCAG 2.2 at level AA. It is partially compliant, because it hasn't been tested manually.

## How it was tested

- Automated axe-core scans of every view, an organisation profile, a topic drill-down, the details dialog with its decision link and a draft, and an Ask answer, against the WCAG 2.0 to 2.2 A and AA rules and best practice. Last run 3 November 2026: no violations.
- Contrast of text on coloured blocks (treemaps, family-tree blocks, chosen topic tiles and hero tiles), measured in Chromium in light and dark themes. Last run 3 November 2026: every pair meets WCAG contrast.
- Width: no view scrolls sideways at 320, 390, 768 or 1366 pixels; wide tables scroll inside their own box. Last run 3 November 2026.
- Scripted keyboard tests: skip link, sorting, paging focus, the details panel's focus trap and return, and the browser's Back button.
- Checks in the page itself, every time it opens: listed under About, Method and checks.

## Known issues

- Not yet tested manually with screen readers, magnifiers at 400% zoom or speech input (roadmap item RM-04).
- The line map and reference graph scroll sideways on small screens; use their list alternatives.
- Some repository descriptions are written by their owners and aren't in plain English.
- Tables with many columns need scrolling on phones.
- The contact and problem-report forms are on GitHub. They need a free GitHub account, and what you write there is public. A private contact form is planned (roadmap item RM-17).

## If you can't use part of the catalogue

Use the [contact form](https://github.com/cyberdudeuk/github-repos-asset-catalogue/issues/new?template=contact.yml) to say what you need, such as information from a view in another format, and we'll reply there. Every view also has a link to report a problem with that page.

## Enforcement

If you're not happy with how we respond to your complaint, contact the Equality Advisory and Support Service (EASS).

## Preparation of this statement

Prepared on 3 November 2026 and reviewed with each release. It stays a draft until a manual audit has been done.
