# User guide

Three levels. Start where you are and move on when you're ready.

| Level | Who it's for | By the end |
| --- | --- | --- |
| [New to GitHub](beginner.md) | You have never used GitHub, or you've only followed a link to it. You don't need to write code. | Understand what GitHub is, read a project's page with confidence, and use this catalogue to find code that matters to your work. |
| [Intermediate](intermediate.md) | You can find your way around a repository and want to judge a project, contribute to one or look after your own. | Judge whether a project is well looked after, take part through issues and pull requests, and know what good looks like in government. |
| [Advanced](advanced.md) | You run repositories, organisations or migrations, or build on this catalogue's data. | Secure and automate repositories, plan moves between organisations without breaking anything, and reuse the catalogue's data and feeds. |

In the catalogue itself, the same guide is under Start here, then the user guide. For step-by-step walkthroughs, see [Guided tours and tutorials](tours.md).
